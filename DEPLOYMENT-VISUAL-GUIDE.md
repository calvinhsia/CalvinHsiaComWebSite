## How Routing Works

### Without staticwebapp.config.json
```
User visits: https://yourapp.azurestaticapps.net/logo
                         ?
Azure checks: Do I have a file at /logo?
                         ?
              NO ? Return 404 ?
```

### With staticwebapp.config.json
```
User visits: https://yourapp.azurestaticapps.net/logo
                         ?
Azure checks: Do I have a file at /logo?
                         ?
              NO ? Check config
                         ?
     navigationFallback: "index.html"
                         ?
     Return index.html ?
                         ?
Blazor JavaScript loads and routes to Logo component
```

## The Copy Command

```yaml
- name: Copy Static Web App Config to wwwroot
  run: |
    if [ -f "./dist/staticwebapp.config.json" ]; then
      cp ./dist/staticwebapp.config.json ./dist/wwwroot/
      echo "? Copied staticwebapp.config.json to wwwroot"
    fi
```

**Why this works**:
1. `dotnet publish` puts config in `dist/` (root)
2. Azure expects it in `wwwroot/` (where index.html is)
3. We copy it to the correct location
4. Azure finds it and configures routing correctly

## Key Takeaways

1. **Location matters**: Azure looks for config in the same folder as `index.html`
2. **Publish puts it in root**: `dotnet publish` outputs config to publish root
3. **Copy step needed**: Must copy config from root to wwwroot
4. **Enables routing**: Config tells Azure how to handle Blazor's client-side routes

## Common Mistakes

? **Mistake 1**: Not copying config to wwwroot
```yaml
app_location: "dist/wwwroot"  # Config not here ? 404s
```

? **Mistake 2**: Wrong app_location
```yaml
app_location: "Client"  # Not built/published ? 404s
```

? **Mistake 3**: Missing navigationFallback in config
```json
{
  // Missing this section ? 404s for routes
  "navigationFallback": {
    "rewrite": "index.html"
  }
}
```

? **Correct Setup**:
1. Config file in `wwwroot/`
2. `app_location` points to `dist/wwwroot`
3. `navigationFallback` configured
4. `skip_app_build: true` (we already built)
